# System Prompt 结构化 Spec

## 背景

当前系统提示是 `agent.py` 里的三段全局文本：`SYSTEM_PROMPT` + `PLAN_MODE_SUFFIX`，`system_prompt()` 按模式二选一**整体返回**。问题：

- 稳定指令与环境信息、会话开关**混在一个字符串**，无法针对 Anthropic 缓存最大化（前缀一变全失效）。
- 工具规则只在工具描述里出现一次，遵守率依赖单一路径。
- plan mode 是整体替换系统提示，无法按轮次控制注入频率。

目标：把 Codepilot 从「能干活」升级为「干得好」——通过**结构化分层 + 缓存断点 + 动态尾块注入 + 关键规则双重强化**，在省成本的同时提高对约定的遵守率。

## 目标

- 把全局指令拆成按职责、按优先级排列的模块，便于日后插入新模块。
- 稳定指令与工具描述走**可缓存前缀**；环境信息与动态指令走**断点后尾块**，最大化 Anthropic 缓存命中。
- 关键工具规则在**全局指令与工具描述**中双重出现，提升遵守率。
- 运行中注入补充指令（特殊标签的 system 尾块），既不污染缓存、也不被模型当作用户输入。
- 会话级开关（如 plan mode）按**轮次**注入：首轮全文、间隔轮次精简、其余跳过，控制注入频率。
- 通过解析 API 返回的**缓存命中字段**验证策略是否生效，并准备典型场景人工对比做定性评估。
- OpenAI 协议作为**降级通道**：无 `cache_control`/`cache` 字段时，退化为合并 system 字符串，功能仍可用。

## 功能需求

- F1：系统提示按职责拆成 **7 个固定模块**（身份、系统约束、任务模式、动作执行、工具使用、语气风格、文本输出），并预留**可选模块插槽**（自定义指令、已激活 Skill、长期记忆），整体按优先级从前往后拼装。
- F2：稳定模块拼成一个**可缓存前缀**，并带一个**缓存断点标记**（Anthropic 语义）。前缀内容在会话内稳定不变。
- F3：**环境信息**（如工作目录、日期）作为动态尾块，追加在缓存断点**之后**，不使稳定前缀失效。
- F4：**会话级动态指令**（如 plan mode 的提示）以**特殊标签的 system 尾块**形式注入，而非 user 消息。
- F5：**关键工具规则**在全局稳定指令和对应工具描述中**双重出现**，提高对「优先用专用工具」「编辑前必先读」等约定的遵守率。
- F6：plan mode 指令按**轮次控制注入频率**——首轮全文、每隔 N 轮精简、其余跳过（N 可配置）。
- F7：解析 Anthropic 返回的**缓存命中字段**（cache read / creation token），并写入日志用于验证策略是否生效。
- F8：OpenAI 协议时，将稳定前缀 + 动态内容**合并为单个 system 字符串**（无断点/标签），功能保持可用。

## 非功能需求

- N1：同时兼容 Anthropic 与 OpenAI 协议，OpenAI 为降级通道。
- N2：稳定前缀内容在会话内逐 token 不变（仅断点后的尾块变化），保证缓存可命中。
- N3：尾块注入不改变 agent 循环既有的工具调用语义。
- N4：模块化可扩展——新增模块只需注册即可拼入，不改主流程。
- N5：不重构现有工具集合与 agent 循环主体，只在其上叠加分层。
- N6：保持既有行为，相关现有测试需同步更新且通过。

## 不做的事（边界）

- 项目指令文件加载（AGENTS.md 类）。
- 长期记忆 / 自动记忆。
- 真实 MCP 接入。
- 自动化评估系统。
- 多断点/逐模块细粒度缓存（方案 C），留待后续章节。
- 不引入第三方 prompt 工程库。

## 验收标准

- AC1：默认（全模块）与 plan mode 两种模式下都能生成结构化系统提示；7 个固定模块齐全且按优先级排列。
- AC2：Anthropic 请求体中系统区为带**缓存断点**的结构，稳定前缀全部位于断点之前。
- AC3：环境信息与动态尾块位于断点之后，且稳定前缀文本不被改动。
- AC4：plan mode 尾块带特殊标签、不作为 user 消息；按轮注入频率正确（首轮全文/间隔精简/跳过）。
- AC5：关键规则（如「编辑前必先读」）同时出现在全局稳定块与对应工具描述中。
- AC6：Anthropic 缓存命中字段被解析并能写入日志。
- AC7：OpenAI 协议降级为合并 system 字符串，功能可用、不报错。
- AC8：现有全量单测通过，且新增的分层/注入/降级相关单测覆盖。
- AC9：典型场景人工对比（有/无结构化）可记录为定性评估结果。
- AC10：新增一个模块只需注册即可拼入，不改主流程。
