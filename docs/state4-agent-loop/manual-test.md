# CodePilot Agent Loop 手动测试指南

> 本文档列出 **无法通过自动化测试覆盖、需要人工在真实环境中验收** 的项。
> 自动化测试（CI/CD）已覆盖功能逻辑、事件流、分批执行等核心行为；
> 本文档聚焦 **TUI 交互、实时渲染、端到端场景** 等需要"眼见为实"的验收项。

---

## 测试环境准备

```bash
# 1. 确保已安装开发依赖
pip install -e ".[dev]"

# 2. 配置 API key（必须真实可用）
# 编辑 config.yaml，填入你的 Anthropic 或 OpenAI API key
# 示例：
# providers:
#   - name: claude
#     protocol: anthropic
#     model: claude-3-5-sonnet-20241022
#     api_key: sk-ant-xxx
#     base_url: https://api.anthropic.com

# 3. 启动应用
python -m codepilot
```

## 手动测试项

### M1: 应用启动

**操作：** `python -m codepilot`

**验收标准：**
- ✅ TUI 正常启动，无报错
- ✅ 显示 CodePilot logo、版本号、当前目录
- ✅ 状态栏显示 provider 名称 + 模型名
- ✅ 输入框可用，光标闪烁

---

### M2: TUI 实时渲染（流式文本）

**操作：** 发送一条简单消息，如「你好」

**验收标准：**
- ✅ 模型回复**逐字显示**（不是整段突然出现）
- ✅ 流式过程中状态栏显示「Imagining… (Ns)」计时
- ✅ 完成后显示总耗时（如「── 1.2s」）
- ✅ 回复内容完整、无截断

---

### M3: 工具调用展示

**操作：** 发送需要工具的任务，如「读一下当前目录的 config.yaml」

**验收标准：**
- ✅ 工具调用时显示 `● read(config.yaml)`（灰色圆点 + 工具名 + 参数）
- ✅ 工具执行完成后更新为 `● read(config.yaml)`（绿色摘要，如「12 lines」）
- ✅ 如果有错误，显示 `✕ tool_name: error message`（红色）
- ✅ 工具行与文本回复之间有合理间距

---

### M4: 状态栏显示（轮次 + Token 用量）

**操作：** 发送一个需要多轮工具调用的任务，如「读 app.py 并总结它的功能」

**验收标准：**
- ✅ 循环中状态栏显示「第 N/M 轮」（如「第 1/10 轮」→「第 2/10 轮」）
- ✅ 每轮结束后显示 token 用量（如「1234+567 tokens」）
- ✅ 轮次和 token 数随循环推进而更新

---

### M5: Esc 取消循环

**操作：**
1. 发送一个耗时较长的任务（如「读整个 codepilot 目录并总结」）
2. 在工具执行过程中按 **Esc**

**验收标准：**
- ✅ 立即停止，不再发起新请求
- ✅ 对话区显示「── 已取消」
- ✅ 输入框立即恢复可用（可继续发下一条消息）
- ✅ 终端回显正常，无残留异步任务报错

---

### M6: Plan Mode 两段式

**操作：**
1. 输入 `/plan`（不带消息）→ 回车
2. 发送「帮我写一个读取 JSON 文件的工具」
3. 观察模型行为
4. 输入 `/do` → 回车
5. 再次发送同样的请求

**验收标准：**
- ✅ `/plan` 后状态栏显示「Plan Mode」
- ✅ 计划模式下模型**只使用只读工具**（read/glob/grep），不调用 write/edit/run
- ✅ 如果模型尝试调用 write/run，会被拒绝并回传错误（模型应自动改用只读工具）
- ✅ 模型输出计划文本后停止（不自动执行）
- ✅ `/do` 后状态栏恢复，放开全部工具
- ✅ 再次发送请求时，模型可以调用 write/edit/run 执行计划

---

### M7: 界面不阻塞

**操作：** 发送一个需要多轮工具调用的任务，在工具执行期间尝试：
- 滚动对话历史
- 点击输入框（应该被禁用，但界面不应卡死）

**验收标准：**
- ✅ 对话区可以正常滚动（查看之前的消息）
- ✅ 界面不卡顿、不冻结
- ✅ 工具执行完成后输入框自动恢复可用

---

### M8: 退出整洁

**操作：**
1. 完成一次对话后，按 **Ctrl+C** 退出
2. 或者输入 `/exit` 退出

**验收标准：**
- ✅ 终端恢复正常（可以输入其他命令）
- ✅ 无残留的异步任务报错
- ✅ 终端回显正常（不会出现乱码或错位）

## 端到端场景（E2E）

以下场景模拟真实使用，验证 Agent 的自主完成能力。

### E2E-1: 读文件并总结

**操作：** 发送「读一下 codepilot/agent.py 并总结它的核心逻辑」

**验收标准：**
- ✅ Agent 自动调用 `read` 工具读取文件
- ✅ 无需催促，自动进入分析并输出总结
- ✅ 总结内容基于文件实际内容，非凭空编造

---

### E2E-2: 改代码并验证

**操作：** 发送「把 config.py 的 AgentConfig 的 max_rounds 默认值改成 20，然后跑一下测试确认没报错」

**验收标准：**
- ✅ Agent 自动调用 `edit` 修改代码
- ✅ 自动调用 `run` 执行测试
- ✅ 如果测试失败，自动分析并修复（可能需要多轮）
- ✅ 最终测试通过后停止，输出确认信息

---

### E2E-3: 死循环兜底

**操作：** 构造一个持续需要工具的任务，如「不断读取当前目录下的所有文件并列出它们的大小」

**验收标准：**
- ✅ 循环在达到迭代上限（默认 10 轮）后自动停止
- ✅ 显示明确提示：「达到迭代上限（10 轮），已停止」
- ✅ 不会无限进行下去

## 常见问题排查

### Q: 启动时报 `ModuleNotFoundError: No module named 'textual'`

**解决：** `pip install -e ".[dev]"`（或至少 `pip install textual`）

---

### Q: 发送消息后无响应，状态栏一直显示「Imagining…」

**可能原因：**
1. API key 无效或过期
2. 网络问题（无法访问 API）
3. 模型配额用尽

**排查：** 检查终端是否有 HTTP 错误输出（如 `HTTP 401: Unauthorized`）

---

### Q: 工具调用时报「用户拒绝执行」

**原因：** `run` 工具需要用户确认。在 ConfirmScreen 中选择「批准执行」或「始终允许」。

---

### Q: Esc 取消后输入框仍被禁用

**可能原因：** 取消逻辑未正确触发，或 Worker 未正常退出。

**排查：** 检查终端是否有异步任务报错；重启应用后重试。
